03self-hosted · python · stdlib

yobimessage

自托管聊天式消息面板：在 Tailscale 内网里像微信一样按会话查看、直接回复 Yobiru 消息。单文件 Python 仅用标准库，双信箱合一、reply_to 链自动归组会话，只绑内网地址、不接触凭据的安全设计。

源码 ↗
04fintech · paypal · ai-tutor

InvestDojo

付 $1 跟 AI 学一堂投资课的静态单页：PayPal SDK 沙箱支付解锁课程，OpenRouter 驱动 AI 助教先提问再讲解，超纲问题诚实说「这节还没讲到」；课后测验 + 本地学习记录，API Key 只存页面内存。
